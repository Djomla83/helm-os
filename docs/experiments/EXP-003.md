# EXP-003: Kontrolisana instalacija i aktivacija

**Status:** Planned — nije izvršeno.\
**Vlasnik / reviewer:** nisu dodeljeni.\
**Odobren budžet:** nije određen. Bez odobrenja nema novih troškova.

## Hipoteza

Profil i staging mogu dati ponovljiv install bez host privilegija.

## Preduslovi i ulazi

Odobren mali installer; isolated lab; definisana očekivana instalacija; tačan runtime.

## Postupak

Prijem/hash → plan → odobrenje → staging → test → aktivacija. Ponoviti isti zahtev i izazvati kontrolisani neuspeh.

Pre početka fiksirati verzije, hardver, scenarije i očekivanja. Svako odstupanje od
plana dokumentovati u izveštaju. Čuvati neuspešne pokušaje i razlog blokiranog koraka.

## Kriterijum pozitivnog ishoda

Jedna jasna aktivna verzija, razumljiv log i očuvan prethodni program pri neuspehu.

## Negativan ili neodlučan ishod

Delimična aktivacija, root zahtev bez razloga, duple instalacije ili neželjene host izmene.

## Granice i sigurnost

Ne objavljivati installer bez prava; format paketa još nije stabilan.

## Isporuka

lista nepoznatog i preporuka za odluku. Plan ne popunjavati izmišljenim rezultatima.
